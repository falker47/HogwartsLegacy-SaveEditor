Hogwarts Legacy Save Editor & Manager
=====================================

SHORT DESCRIPTION (for GitHub sidebar)
--------------------------------------
Windows save manager that integrates local backups, hlsaves compression/decompression and an embedded HLSGE editor through PyWebView.

TOPICS / TAGS
-------------
hogwarts-legacy, save-editor, python, gui, save-manager, backup-tool, customtkinter, pywebview, game-tools

CURRENT RELEASE
---------------
v1.0.4

POSITIONING
-----------
This is an integration project, not a new save-format implementation:
- Python/CustomTkinter desktop manager
- local save discovery and backups
- hlsaves for GVAS database compression/decompression
- HLSGE-derived embedded editor
- PyWebView bridge for the edit/write-back workflow
