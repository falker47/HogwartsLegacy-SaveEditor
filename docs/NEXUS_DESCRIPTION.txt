[size=5][b]Hogwarts Legacy Save Editor & Manager v1.0.4[/b][/size]

A Windows desktop workflow for locating, backing up and editing Hogwarts Legacy saves without manually moving files between a save manager and a browser editor.

[line]

[size=4][b]FEATURES[/b][/size]
[list]
[*][b]Save discovery:[/b] detects the standard Hogwarts Legacy save location, with manual override and persistent configuration.
[*][b]Automatic backups:[/b] creates a backup before an edited save is written back.
[*][b]Integrated editor:[/b] opens the HLSGE-derived editor inside PyWebView next to the manager.
[*][b]Automatic write-back:[/b] the editor's Download action is intercepted locally and the edited database is recompressed through hlsaves.
[*][b]Oodle discovery:[/b] checks common Steam/Epic installations first; a wider search or manual selection is available when needed.
[/list]

[line]

[size=4][b]INSTALLATION[/b][/size]
1. Download and extract the release archive.
2. Run [b]HogwartsLegacy-SaveEditor.exe[/b].
3. If the required [code]oo2core_9_win64.dll[/code] is available in a supported local game installation, the app will try to locate it.
4. Otherwise use the explicit search/manual-selection flow.

[b]The Oodle DLL is not bundled with this project.[/b]

The current v1.0.4 application also contains a hash-pinned fallback download from the third-party new-world-tools/go-oodle GitHub release assets. This is not an official Epic Games distribution channel; using a DLL from your own installed game is preferable when available.

[line]

[size=4][b]HOW TO USE[/b][/size]
1. Open the manager.
2. Select a save.
3. Click [b]Edit Save File[/b].
4. Make changes in the integrated editor.
5. Use the editor's [b]Download[/b] action.
6. The bridge recompresses the edited database into the original save path.

Keep an independent backup before experimenting with save editors.
